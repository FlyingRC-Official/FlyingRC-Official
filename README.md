# FlyingRC Official

FlyingRC builds open-firmware UAV hardware for INAV, ArduPilot, Betaflight, and PX4 users.

We design and maintain UAV hardware, firmware targets, configuration examples, and documentation for pilots, builders, and developers using open flight-control ecosystems.

## What We Work On

- Flight controllers for fixed-wing and multirotor aircraft
- ESCs, power modules, and BEC hardware
- CAN, I2C, and SPI sensors
- GPS and navigation modules
- Firmware support for INAV, ArduPilot, Betaflight, and PX4

## Main Repositories

- [FlyingRC-Official.github.io](https://github.com/FlyingRC-Official/FlyingRC-Official.github.io): product wiki, firmware notes, wiring diagrams, and support documentation
- [betaflight-config](https://github.com/FlyingRC-Official/betaflight-config): Betaflight target definitions and configuration files for FlyingRC flight controllers
- [inav](https://github.com/FlyingRC-Official/inav): FlyingRC-maintained INAV fork for board support and target testing
- [ardupilot](https://github.com/FlyingRC-Official/ardupilot): FlyingRC-maintained ArduPilot fork for board targets, CAN sensors, and hardware validation
- [PX4-Autopilot](https://github.com/FlyingRC-Official/PX4-Autopilot): FlyingRC-maintained PX4 fork for H7D Pro and related board support testing

## Support Policy

For firmware, configuration, wiring, or documentation problems, please open an issue in the most relevant repository and include your product name, board revision, firmware version, wiring details, and logs or configuration dumps.

For order, shipping, warranty, or general contact questions, please use the official website contact route.
